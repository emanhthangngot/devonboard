# DevOnboard Product Artifacts

This directory captures the eight bounded product artifacts for the standalone DevOnboard MVP.

## Eight Core Artifacts

1. **[00. Problem Statement](./00_problem_statement.md)**  
   Defines the user problem, current workarounds, product opportunity, and success criteria.
2. **[01. Design Thinking Document](./01_design_thinking_doc.md)**  
   Roots the product in actual user needs and captures Empathize, Define, Ideate, Prototype, and Test notes.
3. **[02. User Persona](./02_persona.md)**  
   Describes the primary junior engineer and secondary tech lead users.
4. **[03. User Journey Map](./03_journey_map.md)**  
   Maps Discover, Aware, Convert, Retain, and Advocate stages.
5. **[04. DVF Assessment](./04_dvf.md)**  
   Evaluates desirability, viability, and feasibility.
6. **[05. Product Roadmap](./05_product_roadmap.md)**  
   Defines Now, Next, and Later themes.
7. **[06. PRD](./06_prd.md)**  
   Defines what the MVP must build and why.
8. **[07. Prototype Plan](./07_prototype.md)**  
   Defines the web prototype flow and validation focus.

## Supplemental Artifact

- **[08. Pitch Deck Outline](./08_pitch_deck.md)** supports demo storytelling but is not part of the eight core artifact checkpoint.
