# Codebase Institutional Memory: Evidence and Research

## Impact & ROI Evidence

*   **AI can speed scoped coding tasks:** A controlled GitHub Copilot study found developers completed a JavaScript HTTP server task 55.8% faster with Copilot than without it.
*   **AI also increases verification needs:** DORA research reports AI adoption can improve developer flow and productivity while also creating risks to delivery performance when systems and review practices do not mature.
*   **Enterprise AI adoption is broad:** The Stanford AI Index 2025 reports that AI adoption across organizations has become widespread, making AI-assisted workflows a baseline expectation rather than a novelty.

## Research & Studies

*   **Peng et al., GitHub Copilot productivity experiment:** Shows strong productivity gains for a bounded programming task, supporting the "AI accelerates output" premise.
*   **Google Cloud DORA reports:** Emphasize that AI is an amplifier; strong delivery and review systems matter more as code velocity rises.
*   **Stanford HAI AI Index:** Provides macro evidence that AI adoption and investment are accelerating across industries.

## Adoption Signals

*   AI coding assistants are now integrated into mainstream IDEs and developer workflows.
*   Agentic coding workflows are increasing the need for repo-specific context and verifiable outputs.
*   Developer platforms are adding chat, code search, summaries, and workflow automation, indicating demand for better context systems.

## Counter-Evidence / Skeptic's View

*   AI productivity gains are strongest on bounded tasks; complex multi-file reasoning and proprietary context remain difficult.
*   Faster code generation can increase review burden if teams lack automated tests and clear architecture context.
*   Poorly grounded AI tools risk becoming thin wrappers that produce confident but unreliable explanations.
